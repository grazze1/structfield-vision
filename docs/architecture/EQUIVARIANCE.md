# Structural equivariance infrastructure

## Purpose

Stage 7 supplies a geometry-aware reference path for regularizing consistency
between an image and a transformed copy of that image. It does not require the
estimator or downstream backbone to be exactly group equivariant. The losses
measure consistency only on pixels whose complete interpolation footprint is
valid.

A typical rotation experiment is:

```python
source_field = estimator(image)
rotated_image = rotate_tensor(image, phi)
observed_field = estimator(rotated_image.tensor)
expected = rotate_structural_field(source_field, phi)

mask = rotated_image.equivariance_valid_mask & expected.equivariance_valid_mask
loss = OrientationEquivarianceLoss()(
    observed_field.orientation_prob,
    expected.field.orientation_prob,
    mask,
)
```

Both estimator branches remain in the autograd graph. This is a symmetric
consistency regularizer, not an implicit teacher/student stop-gradient method.

## Coordinate and sampling convention

The public field convention is `x-right,y-down`, with positive rotation
counter-clockwise on the displayed image. `GeometricTransform` describes a
same-canvas transform about the pixel center:

```python
GeometricTransform(rotation_rad=phi, scale=s)
```

`scale > 1` magnifies the source. For a canvas of height `H` and width `W`, the
normalized output-to-input affine map used by `affine_grid` is:

```text
[[ cos(phi)/s, -sin(phi) H/(s W), 0 ],
 [ sin(phi) W/(s H),  cos(phi)/s,   0 ]]
```

The aspect-ratio factors are required for a true pixel-space rotation on a
rectangular canvas. Sampling is bilinear with `align_corners=False`. Tensor
transforms use zero padding; values outside the valid region must never be used
for equivariance comparison.

## Validity mask

Every tensor or field transform returns:

```text
equivariance_valid_mask [B,1,H,W], bool
```

The mask is generated by bilinearly warping an all-valid source support map
with zero padding and accepting a pixel only when its complete interpolation
footprint has support one, within floating-point tolerance. An optional boolean
`source_valid_mask` is propagated through the same operation, so holes and
pre-existing invalid regions are excluded as well as geometric padding.

All three Stage-7 losses require this mask as an explicit positional argument;
there is no unmasked default. A floating mask in `[0,1]` may also be supplied
to the loss as a fractional pixel weight. Exactly invalid locations are safely
zeroed before subtraction or squaring, preventing overflow at excluded pixels
from leaking into the result as `NaN`.

## Structural-field transform

`transform_structural_field` applies one sampling grid to every component and
then applies the semantic value transform:

- Orientation posterior maps are spatially warped, normalized, and transported
  by `+phi` on the axial `[0,π)` circle. Arbitrary shifts use periodic linear
  mass interpolation; exact-bin shifts are exact mass rolls.
- Top orientation modes are spatially interpolated through doubled-angle
  vectors, shifted by `+phi`, and wrapped to `[0,π)`. This avoids the false
  linear mean of angles near the axial wrap.
- Orientation entropy is recomputed from the transformed distribution.
- Frequency mean is divided by `s`; frequency variance is divided by `s²`.
- Frequency candidate metadata is divided by `s`.
- Scale posterior maps are spatially warped and normalized; selected scale and
  scale-candidate metadata are multiplied by `s`.
- Coherence and structural uncertainty are spatially warped and clamped to
  their valid unit interval.

Invalid output values are filled deterministically in a schema-valid form so a
complete `StructuralField` can still be returned. They remain semantically
excluded by `equivariance_valid_mask`.

Convenience functions provide rotation-only and scale-only forms for both
tensors and structural fields. Float16 and bfloat16 inputs use float32 sampling
arithmetic and return the original dtype; float32 and float64 are preserved.

## Reference losses

The parameter-free loss classes compare already aligned maps:

- `OrientationEquivarianceLoss`: squared error averaged over orientation bins,
  followed by mask-weighted pixel mean.
- `FrequencyEquivarianceLoss`: absolute error averaged over channels, followed
  by mask-weighted pixel mean.
- `UncertaintyEquivarianceLoss`: the same masked L1 reference reduction.

Prediction and target must have identical BCHW shape, dtype, and device. The
mask must be aligned `[B,1,H,W]` and contain at least one positive location.
Both compared branches receive gradients; masks are detached geometry metadata.
Low-precision inputs use float32 loss arithmetic.

## Limitations and provenance

The transform utility and three losses are project-authored independent
implementations built from PyTorch primitives. No third-party implementation or
new dependency is copied or vendored.

This is a same-canvas bilinear reference transform. It does not model lens
distortion, anisotropic scaling, perspective transformations, or learned
registration. Discrete posterior interpolation is an approximation at arbitrary
angles. These objectives are transparent baseline regularizers, not evidence of
exact architectural equivariance or a final research definition. Whole-project
licensing remains subject to the final provenance gate and
the Apache-2.0 and third-party boundaries recorded in `NOTICE.md`.
