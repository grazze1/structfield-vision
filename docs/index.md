# StructField-Vision 1.0

StructField-Vision provides a deterministic analytic estimator and a validated,
immutable data model for probabilistic image structure. Version 1 supports
Linux x86_64 and Python 3.11.

Start with [getting started](getting-started.md), then review the
[field conventions](concepts.md), [tutorials](tutorials.md), and
[API reference](api.md). Reproduction and release evidence is separated from
research context and historical competition material.
