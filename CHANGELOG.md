# Changelog

All notable changes follow Semantic Versioning.

## 1.0.0 - 2026-09-01

- Stabilized the structural-field, estimator, benchmark, metric, config, CLI,
  visualization, dataset, and checkpoint boundaries.
- Made `orientation_prob` the sole persisted orientation state and added dynamic
  separated-mode derivation.
- Added strict/trusted validation, schema 1.0, safe legacy-field migration,
  integrity-checked CLI bundles, packaged config parsing, typing marker, examples,
  documentation site, release baselines, and CPU/CUDA qualification tooling.
- Moved research adapters, reliability/corruption/equivariance components,
  heuristic uncertainty, and reference applications behind an experimental label.
- Removed broad 0.3 top-level re-exports and core Matplotlib dependency.
